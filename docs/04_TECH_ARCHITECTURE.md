# 04. Technical Architecture

## 1. Stack
| Layer | Choice | Why |
|-------|--------|-----|
| Framework | Next.js (latest stable, App Router), static export friendly | Static pages, great on Vercel |
| Language | TypeScript (strict) | Catches content mistakes at build |
| Styling | Tailwind CSS (latest) + CSS variables for theme tokens | Fast, matches the token table in the UI spec |
| Motion | GSAP + ScrollTrigger, Lenis | Precise scroll scrubbing and pinning |
| Theme | `next-themes` (class strategy) | No flash on load |
| Validation | zod | Validates content files at build |
| Forms | Native form + small client component | No backend, opens WhatsApp |
| Images | sharp (dev dependency only) | Local compression to WebP |
| Testing | Vitest, Playwright, @axe-core/playwright, Lighthouse CI, linkinator | See `05_TESTING_QA.md` |
| Lint/format | ESLint, Prettier, custom content lint script | Enforces writing and icon rules |
| Hosting | Existing Vercel project (Hobby) | Keeps andrescreation.vercel.app |

No database. No environment variables. No runtime fetches.

## 3. Content model (`src/content/schema.ts`)
```ts
import { z } from "zod";

export const ProjectSchema = z.object({
  slug: z.string().regex(/^[a-z0-9-]+$/),
  title: z.string().min(2),
  category: z.array(z.enum(["Brand", "Product UI", "Web"])).min(1),
  year: z.string(),
  role: z.string(),
  tools: z.array(z.string()).default([]),
  summary: z.string().max(110),
  overview: z.string(),
  challenge: z.string().optional(),
  approach: z.string(),
  outcome: z.string(),
  cover: z.string().startsWith("/images/projects/"), // base path, no suffix
  gallery: z.array(z.string()).default([]),
  liveUrl: z.string().url().optional(),
  codeUrl: z.string().url().optional(),
  marqueeRow: z.union([z.literal(1), z.literal(2)]),
  order: z.number(),
  draft: z.boolean().default(false),
});
export type Project = z.infer<typeof ProjectSchema>;
```
- `projects.ts` exports `projects` parsed through `z.array(ProjectSchema).parse(...)` so a bad entry fails the build.
- Helper `publishedProjects = projects.filter(p => !p.draft).sort((a,b) => a.order - b.order)`.
- Every image path in content must exist on disk (checked by a unit test).

## 4. Image pipeline (no CDN, Vercel free only)

### 4.1 Script `scripts/optimize-images.mjs`
- Input: everything in `images-raw/` (png, jpg, jpeg, webp, avif, tiff, heic if supported), recursive.
- For each image:
  - `.rotate()` to respect EXIF orientation, strip metadata.
  - Write `<name>-card.webp`: width 800, quality 72, effort 6, smartSubsample.
  - Write `<name>-full.webp`: width 1600, quality 75, effort 6, smartSubsample.
  - `withoutEnlargement: true`.
  - Generate a 16px wide WebP, base64 encode it, store in `src/content/blur.json` keyed by base path.
- Output mirrors folders into `public/images/` (projects go to `public/images/projects/<slug>/`, about to `public/images/about/`, etc. based on the top folder name: `images-raw/projects/...`, `images-raw/about/...`).
- Skip if output is newer than source. Print size in KB. Warn if card over 120 KB or full over 300 KB, and exit with code 1 when run with `--strict`.
- `package.json`: `"img": "node scripts/optimize-images.mjs"`, `"img:strict": "node scripts/optimize-images.mjs --strict"`.
- `.gitignore`: `images-raw/`.

### 4.2 Rendering
- `<ProjectImage base alt sizes priority />` renders an `<img>` (or `next/image` with `unoptimized`) with:
  - `src = base + "-card.webp"`
  - `srcSet = "<card> 800w, <full> 1600w"`
  - `sizes` passed per context (cards: `(max-width: 768px) 85vw, 420px`; case study cover: `100vw`)
  - explicit `width` and `height` to prevent layout shift
  - `loading="lazy" decoding="async"`, except when `priority` (then `fetchpriority="high"`, eager)
  - blur placeholder background from `blur.json`
- `next.config`: `images: { unoptimized: true }`. Never use Vercel Image Optimization.

### 4.3 Hero video
Andre runs this once (ffmpeg or HandBrake), documented in README:
```bash
ffmpeg -i hero.mov -vf "scale=1920:-2" -c:v libx264 -crf 28 -preset slow -an -movflags +faststart public/video/hero.mp4
```
- Target under 5 MB, no audio.
- Tag: `<video autoPlay muted loop playsInline preload="metadata" poster="/images/hero-poster.webp">`.
- Do not render the `<video>` element on screens under 768px or when `prefers-reduced-motion: reduce` or `Save-Data` is on. Show the poster only.

## 5. Motion implementation notes
- One `SmoothScroll` client component starts Lenis on desktop and connects it to ScrollTrigger (`lenis.on("scroll", ScrollTrigger.update)`, GSAP ticker drives Lenis).
- All GSAP code inside `useGSAP` or `useLayoutEffect` with cleanup. Use `gsap.matchMedia()` as described in the motion spec.
- GSAP is imported only in client components and loaded after hydration so it does not block LCP.
- Marquee is CSS only.

## 6. WhatsApp contact (`src/lib/whatsapp.ts`)
```ts
export function buildWhatsAppUrl(f: { name: string; email: string; type: string; budget?: string; message: string }) {
  const text = `Hi Andre, I'm ${f.name} (${f.email}).\nI'm reaching out about: ${f.type}\nBudget: ${f.budget || "Not specified"}\n\n${f.message}\n\n(Sent from andrescreation.vercel.app)`;
  return `https://wa.me/2349039640382?text=${encodeURIComponent(text)}`;
}
```
- Phone number lives only in `src/content/site.ts`. The function reads it from there.
- Submit opens the URL in a new tab with `noopener`.

## 10. Adding a project later (goes in README)
1. Create `images-raw/projects/<slug>/` and drop `cover.png` plus gallery images in it.
2. Run `npm run img`.
3. Add an entry in `src/content/projects.ts` (copy an existing one).
4. Run `npm run test:all`.
5. Commit and push. Vercel deploys in about a minute.
